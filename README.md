# Saudi Car Import Check

Installable web app that compares the landed cost of importing a new car into Saudi Arabia (from the US, UAE, Germany, South Korea or China) with the local distributor price.

Landed cost = retail − refundable home tax + export markup → FOB; + freight + insurance → CIF; + 5% customs duty; + 15% VAT on CIF + duty; + port, SABER, inspection and plate fees; + the value of the agency warranty given up.

Prices tagged "listing" were checked against public listings in November 2026; "est." prices are base-trim estimates. Indicative only — get a dealer quote before buying.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```
